# Nu Omega Founders Day - Website ebook package

This package contains the latest approved 16-page ebook as of this export. The original ebook and commercial-print versions are unchanged.

## Add to an existing GitHub Pages site

1. Extract this ZIP on your computer.
2. Copy `ebook.html` and the files inside `assets/` into the root of your website repository. Merge with an existing `assets/` folder; keep unrelated files.
3. Commit the files to the branch/folder configured for GitHub Pages.
4. Add a navigation link to `ebook.html`, or paste the section from `embed-snippet.html` into the desired page.
5. After the site finishes publishing, open `ebook.html` and test both the reader and download button.

Use relative paths exactly as supplied. They work with both a custom domain and a project site such as `username.github.io/repository/`. If your page is in a subfolder, adjust the paths accordingly. Do not replace your existing `index.html`.

## Included files

- `ebook.html`: responsive purple-and-gold reader page. Desktop browsers display an embedded PDF; phones get a cover and direct full-screen PDF links.
- `embed-snippet.html`: a ready-to-paste cover/download section for an existing page.
- `assets/nu-omega-founders-day-2026-ebook.pdf`: 15.5 MiB web PDF, 16 pages, with section bookmarks and optimized loading.
- `assets/ebook-cover.jpg`: compressed website cover image.

## Quality

The web PDF uses approximately 150 PPI raster artwork with retained embedded text/fonts and bookmarks. It is designed for online viewing, not commercial printing. Use the separate print edition for the printer. Image detail remains limited by the original source material.

No external scripts, fonts, analytics, or services are required. This package has not been deployed to your website.
